# 目标数据提取与本地源码复制

本工具由当前宿主登记的Go编译运行，只生成数据和脚本，不运行目标架构程序。`just test-arm-data`执行行为测试与`go vet`，临时数据和缓存均位于主仓`build/`。

每次调用指定`--dest`。归档内容的临时文件分配到程序执行时当前目录的`build/tmp/`，完成后清理；兼容旧调用的`--work`参数，但不使用该路径。提取和配置生成要求目标尚不存在，使用宿主不覆盖重命名发布；已存在目标不会被覆盖。普通输入要求单链接，输出采用独立普通文件；写入前检查可用空间，写入后不足50 GiB时向标准错误打印中文警告并继续，不再中止（#382）。归档中的符号别名在内容完整、目标不越界且无循环时展开为独立副本；硬链接与特殊条目拒绝。

| 操作 | 输入与结果 |
| --- | --- |
| `rust` | `--src`指向登记的Linux arm64工具链仓目录。核验Rust 1.97.1归档分片和总摘要，仅提取GNU arm64标准库与版权文件，不提取编译器。 |
| `debs` | `--src`指向已经下载的Debian包目录，由本机`dpkg-deb`读出arm64或all架构包的数据，生成目标头文件、库、pkg-config及许可证目录。它不负责下载或安装包。 |
| `config` | `--llvm`为本机LLVM 22目录，`--sysroot`为arm64目标根，生成显式指定目标、LLD、GNU运行库和pkg-config目录的编译脚本及Meson配置。 |
| `source` | `--src`为已有gzip源码归档，`--sha256`为登记摘要，校验后生成独立源码目录。 |
| `git` | `--src`为干净且对象已完整的本地Git仓，可重复传`--path`只选择所需文件或目录；生成独立源码副本。 |
| `git-check` | 使用与`git`相同的源和选择，逐字节核对已有副本的内容、数量、模式与普通文件身份，不改写副本。 |
| `git-refresh` | 按`git`的源和选择复用有效副本；缓存校验失败时生成独立候选，逐字节复核后原子交换，旧副本保留。 |
| `git-set` | 重复传`--repo 前缀=本地仓目录`，可用`--path 前缀=仓内路径`限定输入。把多个已登记源码仓作为同一个范围提取，支持范围内跨仓文件别名，仍拒绝越界或缺失目标。 |
| `git-set-check` | 按相同源码集合逐字节复核已有副本，不改写内容。 |
| `git-set-refresh` | 按相同源码集合复用有效副本或重建无效缓存，旧副本保留。 |
| `cargo-bin` | `--src`指向Cargo提升到`release/`的程序。Cargo默认把`deps/`内真实产物硬链接到该路径；多链接时定位`deps/`内同身份的唯一文件，移除提升别名，再把单链接产物复制为`--dest`独立普通文件。单链接产物直接复制；找不到唯一同身份文件时失败并保留输入。 |

Git操作清除继承的Git路径环境，禁止传输协议及按需联网取对象；读取前后检查工作树、索引隐藏标记和版本状态。源码身份由调用方核对登记URL、标签和上级仓引用，本工具输出URL与标签，不持久记录提交对象值。Git复制与复核不计算源码内容摘要，副本通过字节比较确认。

源码集合的前缀必须是互不重叠的相对路径，每个路径选择必须对应已声明的仓。所有成员完成读取且版本状态未变后才生成候选；跨仓别名只能指向本次集合已经包含的内容，不能访问其它工作树或宿主文件。`git-set`、`git-set-check`和`git-set-refresh`必须使用相同前缀与路径选择。

刷新入口固定工作父目录句柄，核对当前属主、原路径、模式及inode后，将已有`0775`、`0700`或含setgid的职责目录设为`0755`；拒绝目录链接、错误属主与其它用户写权限，错误包含实际路径、模式和UID。取得目标同级的`<目录名>.copy.lock`独占目录锁；有效缓存保留原身份。模式、大小、内容、文件集合或独立文件身份不符时，新候选按普通文件`0644`、可执行文件及目录`0755`生成并重新校验。macOS使用`RENAME_SWAP`，Linux使用`RENAME_EXCHANGE`；交换前后核对父目录、候选和原目标身份。旧副本保留在目标同级的`arm-replaced-*/source`，不删除、不修改原字节及模式。源码读取失败和锁占用仍拒绝；身份变化时保留两份目录并报告失败。

Go行为测试覆盖Git、普通目录和多仓集合的五种缓存失败，另核对有效缓存复用、目录链接拒绝、锁占用及源码读取失败。父目录回归覆盖三种模式、三种源码输入及有效／无效缓存18项；原缓存和父目录其它文件的字节、模式及inode保持。2026-10-04 macOS18项先失败后通过，完整包31.251秒退出0；nuc Linux amd64的父目录与既有缓存共38子项于03:20:02至03:20:08UTC退出0。macOS arm64与Linux amd64／arm64程序编译通过；Linux arm64运行、nuc原发行镜像命令和Guest未复验。

本机已执行归档、路径、别名展开、独立文件、内容不一致、Git环境隔离及编译参数行为测试，并从登记Rust归档实际提取标准库。模拟编译器的参数测试不代表真实交叉编译；完整Debian目标根、Linux镜像构建和设备发行仍须在各自正式入口验收。
